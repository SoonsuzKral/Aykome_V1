## ✅ Oracle DB Dump

```
Dosya: aykome_14aug2026.dmp (6.3 MB)
Schema: AYKOME_USER
Tablolar: 59 adet
Kayıtlar: ~5.000+
Format: Oracle Data Pump (.dmp)
```

**Sunucuya kurulum:**
```bash
# 1. Dizin oluştur
mkdir -p /opt/oracle/dump
cp aykome_14aug2026.dmp /opt/oracle/dump/

# 2. SYS ile directory + grant
sqlplus sys/SIFRE@sunucu:1521/freepdb1 as sysdba
CREATE OR REPLACE DIRECTORY DUMP_DIR AS '/opt/oracle/dump';
GRANT READ, WRITE ON DIRECTORY DUMP_DIR TO aykome_user;
EXIT;

# 3. Kullanıcı oluştur (yoksa)
CREATE USER aykome_user IDENTIFIED BY aykome123;
GRANT CONNECT, RESOURCE, DBA TO aykome_user;
ALTER USER aykome_user QUOTA UNLIMITED ON USERS;

# 4. Import
impdp aykome_user/aykome123@sunucu:1521/freepdb1 \
  schemas=aykome_user \
  directory=DUMP_DIR \
  dumpfile=aykome_14aug2026.dmp \
  logfile=aykome_import.log
```
